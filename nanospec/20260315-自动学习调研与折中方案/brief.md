# 自动学习调研与折中方案

## 背景

用户希望沿着“自动学习 / 自动积累”这条线开一个新任务，先做调研，不急着追求全自动。

当前已知前提：

- ECC 这一侧现在更偏强依赖 hooks。
- 自动学习 / 积累很重要，但 prompt 优化本身仍然需要人类参与。
- AI 只要能在一定程度上辅助人类沉淀经验，就已经有价值。

## 目标

1. 调研三个参考 repo 是否已经具备“自动学习 / 积累”相关能力。
2. 判断这些能力分别依赖什么载体，尤其是否强依赖 hooks、插件运行时或特定平台。
3. 给出几种折中方案，覆盖“非全自动但能持续积累”的实现思路。

## 约束

- 默认沿用当前仓库既有三仓库上下文：`everything-claude-code`、`superpowers`、`oh-my-opencode`。
- 不以直接引入重运行时为目标。
- 结论需要优先服务当前仓库“沉淀可复用 prompt 资产”的方向。
