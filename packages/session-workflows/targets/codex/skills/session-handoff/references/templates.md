# Session Handoff 模板

## 文件名

```text
.session/<YYYYMMDD-HHMMSS>-session-handoff.md
```

- 时间使用当前 session 实际结束时间
- 使用绝对时间，不使用相对表述
- `YYYYMMDD-HHMMSS` 采用本地时间

## 文档模板

```md
# Session Handoff

- 项目：`<项目名或仓库路径>`
- 主题：`<这一轮 section / 工作主题>`
- 结束时间：`<YYYY-MM-DD HH:MM:SS TZ>`
- 触发原因：`<section 完成 / 上下文将满 / 准备换窗口 / 其他明确原因>`

<1 到 3 段，说明这轮 session 已经推进到哪里、当前整体判断是什么。>

- `<事项>`：`<验证证据>`

若无：

- 无已确认有效事项。

## 已完成但未验证

- `<事项>`：`<为什么还没验证>`

若无：

- 无。

- `<尝试 / 路径>`：`<失败原因或不该重试的依据>`
```
