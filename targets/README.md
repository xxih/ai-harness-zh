# 分发与 Target 包层

`targets/` 保存面向具体 AI 工具的分发快照与 target 包。这里允许出现平台绑定内容，但默认应保持**薄、可回溯、可从 `src/` 映射**。

## 当前职责

- 把 `src/` 中的共享源资产按某个运行时需要做平铺、映射或最小包装
- 保存工具专属的运行时配置，例如角色注册、target 级 `_AGENTS.md`、局部适配文件
- 作为“从共享源资产到具体工具包”的中间层，而不是永久容纳所有工具实现的大仓

## 基本约定

- `src/domains/<domain>/` 是源资产真相来源
- `targets/<tool>/` 主要保存目标工具所需的平铺副本、适配层和最小运行时配置
- 当前阶段 target 包默认按需手工维护；若未来出现自动生成物，应放到 `dist/` 而不是手改生成物
- `targets/` 下这类 AGENTS 分发位统一命名为 `_AGENTS.md`

## 何时继续留在 `targets/`

- 还只是薄分发快照
- 主要价值仍来自 `src/` 里的共享真相
- 还没有形成独立安装、独立发布、独立验证的完整生命周期

## 何时升格为独立 repo

当某个 target 包开始具备以下特征时，应优先拆成单独 repo：

- 需要自己的安装说明、快速开始、示例项目
- 累积大量 target 专属 hooks、scripts、settings、验证逻辑
- 有明确的工具用户群与版本节奏
- 需要独立 issue / release / e2e 验证边界
- 已经可以被用户当作一个单独产品来使用

升格后，当前仓库保留：

- 该 target 的来源映射关系
- 与共享 `src/` 资产的对应关系
- 必要的研究、翻译和高层说明
