# 分发与 Target 包层

`targets/` 保存仍然需要留在当前总仓里的薄分发快照。这里允许出现平台绑定内容，但默认应保持**薄、可回溯、可从 `src/` 映射**。

## 当前职责

- 把当前仍保留在 `src/` 的共享源资产映射成具体工具可消费的目录
- 保存最小运行时配置，例如角色注册和局部适配文件
- 不再长期容纳已经拆成独立 repo 的完整工具包

## 升格规则

当某个 target 包开始具备以下特征时，应优先拆成独立 repo，而不是继续堆在当前仓库：

- 需要自己的安装说明、快速开始、示例项目
- 累积大量 target 专属 hooks、scripts、settings、验证逻辑
- 有独立的用户群与版本节奏
- 已经可以被当作一个独立产品使用
