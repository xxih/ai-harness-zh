# Page Patterns

## 推荐页型

默认建议 `7-9` 页，可按内容密度增减：

1. 封面页
   - 强钩子标题
   - 一句话副标题
   - 明确收益或结果
2. 读者收益页
   - 这组图解决什么问题
   - 适合谁
3. 核心步骤页 A
4. 核心步骤页 B
5. 核心步骤页 C
6. 提醒 / 避坑页
7. 清单 / 总结页
8. 结尾行动页

## 教程型内容的拆页建议

- 原文是操作流程：优先拆成步骤页
- 原文是准备清单：优先拆成清单页 + 提醒页
- 原文是说明文：优先重组为「问题 -> 做法 -> 验证 -> 收尾」
