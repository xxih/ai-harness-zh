# Visual Styles

## 主题选择原则

不要默认所有内容都用同一种“网页卡片风”。先看内容类型，再选主题。

- 教程 / 安装 / 操作流：优先清晰、层级强、按钮感明确
- 清单 / 总结 / 避坑：优先高对比、重点标签明显
- 方法论 / 复盘 / 经验贴：优先更有情绪张力的 editorial 风格

## 当前内置主题

### `clean-notes`

- 适合：教程、步骤、工具配置、清单
- 气质：干净、轻、信息边界清晰
- 特点：高留白、深色标题、低噪点背景、阅读优先

### `warm-handbook`

- 适合：课程、方法笔记、经验总结
- 气质：温暖、手册感、可信赖
- 特点：米色系背景、暖色强调、卡片更柔和

### `editorial-pop`

- 适合：强观点、避坑提醒、标题党钩子页
- 气质：更鲜明、更有封面冲击力
- 特点：高对比标题、强调色更强、视觉张力更大

## 选择建议

- 如果内容步骤多、操作多：先试 `clean-notes`
- 如果内容偏课程、解释型：先试 `warm-handbook`
- 如果封面钩子不够强、需要更抓眼：先试 `editorial-pop`

## 注意

- 主题切换解决的是视觉方向，不解决内容过密
- 如果一页字太多，先拆页，再换主题
