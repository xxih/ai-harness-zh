# 工作流领域

这个领域承载 coding 工作流前半段的可复用资产，重点是先研究、再拆解、再组织执行。

## 范围

- 编码前研究与方案收敛
- 复杂任务拆解与多 agent 编排
- 进入实现前的上下文准备与阶段切分
- 任务容器、共享工作面与 align 纠偏

## 领域规则

- 先定义问题、边界和证据，再进入实现
- 平台运行时术语不要写进核心资产，平台差异继续放到 `targets/`
- 检查清单、委派模板和长示例优先放到各资产自己的 `references/`
- 如果只需要任务容器与纠偏机制，优先使用更纯的 `spec-driven`
- 如果需要目录规范之外的阶段路由和完整 workflow，再使用 `nanospec`
- 当前领域以 `skills/` 为主，`agents/` 与 `commands/` 先保留结构位
