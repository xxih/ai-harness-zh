# In Progress(中文翻译)

仍在开发中的 skill。**没准备好发布** —— 预期会有粗糙边、破坏性变更、被弃用的实验。它们从插件和顶层 README 里排除,直到毕业到稳定 bucket。

- **[review](./review/SKILL.md)** — 沿两条并行轴评审从某固定点起的变更:**Standards**(diff 是否遵循仓库编码规范?)+ **Spec**(diff 是否忠实实现了对应 issue/PRD?)。
- **[writing-beats](./writing-beats/SKILL.md)** — 把文章组织成一段"节拍之旅"(choose-your-own-adventure 风格)。挑起手节拍,只写它,再 pivot 到下一节拍,直到自然结束。
- **[writing-fragments](./writing-fragments/SKILL.md)** — Grill 会话,从你身上挖出"片段"(异质的写作小金块),追加到单一文档作未来文章的原材料。
- **[writing-shape](./writing-shape/SKILL.md)** — 把一份"原材料 markdown"塑造成文章——逐段长出来,每一步都对格式选择争论清楚。
