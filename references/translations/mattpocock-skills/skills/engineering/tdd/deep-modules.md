# 深模块(Deep Modules)

> 原文:[deep-modules.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/tdd/deep-modules.md)

来自 John Ousterhout《A Philosophy of Software Design》:

**深模块** = 小接口 + 大量实现

```
┌─────────────────────┐
│    小接口            │  ← 方法少、参数简单
├─────────────────────┤
│                     │
│                     │
│   深的实现           │  ← 复杂逻辑藏在内部
│                     │
│                     │
└─────────────────────┘
```

**浅模块** = 大接口 + 实现没多少(应避免)

```
┌─────────────────────────────────┐
│       大接口                     │  ← 方法很多、参数复杂
├─────────────────────────────────┤
│  实现很薄                        │  ← 基本就是透传
└─────────────────────────────────┘
```

设计接口时问:

- 方法数能不能减?
- 参数能不能简?
- 能不能把更多复杂度藏进去?
