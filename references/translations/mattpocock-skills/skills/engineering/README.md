# Engineering(中文翻译)

每天用来做代码工作的 skill。

- **[diagnose](./diagnose/SKILL.md)** — 难 bug / 性能回退的纪律化诊断循环:复现 → 最小化 → 假设 → 加 log → 修 → 回归测试。
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — Grill 会话:用现有领域模型挑战你的计划,锻造术语,同步更新 `CONTEXT.md` 和 ADR。
- **[triage](./triage/SKILL.md)** — 用 triage 角色状态机走 issue。
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — 借助 `CONTEXT.md` 领域语言和 `docs/adr/` 决策,寻找"加深模块"的机会。
- **[setup-matt-pocock-skills](./setup-matt-pocock-skills/SKILL.md)** — 在每个仓库初始化 issue tracker / triage 标签 / 领域文档布局,供其它 engineering skill 消费。
- **[tdd](./tdd/SKILL.md)** — 红-绿-重构 TDD 循环。一次构建/修复一个垂直切片。
- **[to-issues](./to-issues/SKILL.md)** — 把 plan / spec / PRD 用垂直切片拆成可独立认领的 GitHub issue。
- **[to-prd](./to-prd/SKILL.md)** — 把当前对话凝练成 PRD 并提交为 GitHub issue。
- **[zoom-out](./zoom-out/SKILL.md)** — 让 agent 拉远视角,从更大格局解释陌生代码。
- **[prototype](./prototype/SKILL.md)** — 写一次性原型来填出设计——要么是验证状态/业务逻辑的可运行 terminal app,要么是同一个路由下多套截然不同 UI 可切换。
