# Triage 标签

> 原文:[triage-labels.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/setup-matt-pocock-skills/triage-labels.md)

Skill 用**五个规范 triage 角色**说话。本文件把这些角色映射到本仓库 issue tracker 中**实际**用的标签字符串。

| mattpocock/skills 里的标签 | 我们 tracker 里的标签 | 含义                              |
| -------------------------- | -------------------- | --------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue          |
| `needs-info`               | `needs-info`         | 等报告人补信息                     |
| `ready-for-agent`          | `ready-for-agent`    | 已完整规格化,AFK agent 可以接手 |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现                       |
| `wontfix`                  | `wontfix`            | 不修                              |

skill 提到角色(例如"打上 AFK-ready triage 标签")时,使用本表对应右列的字符串。

**根据你实际用的词表去改右列。**
