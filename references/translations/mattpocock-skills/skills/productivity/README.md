# Productivity(中文翻译)

通用工作流工具,不限于代码。

- **[caveman](./caveman/SKILL.md)** — "穴居人"模式:极致压缩沟通。Token 砍 ~75%,扔废话保技术准确度。
- **[grill-me](./grill-me/SKILL.md)** — 让 agent 死磕你的计划/设计,把决策树每条分支都问透。
- **[handoff](./handoff/SKILL.md)** — 压缩当前对话为交接文档,让另一个 agent 接班。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 用正确结构 + 渐进披露 + 资源打包写新 skill。
