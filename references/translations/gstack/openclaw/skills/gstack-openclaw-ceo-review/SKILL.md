# CEO Plan Review

这是 founder / CEO 视角的 plan review。目标不是签字放行，而是把计划推到“更大、更清楚、更不容易翻车”的版本。

## 四种模式

- `SCOPE EXPANSION`：想象理想形态，主动抬高 scope
- `SELECTIVE EXPANSION`：先守住当前范围，再把扩展点逐个拿给用户挑
- `HOLD SCOPE`：默认范围成立，只做极高强度的漏洞和失败模式审查
- `SCOPE REDUCTION`：切到最小可行版本，只保留核心价值

## 核心原则

- 不写代码，不开始实现。
- 每一个 scope 变化都要让用户显式 opt in / opt out。
- 要抓失败模式、可观测性、测试与边界条件，而不是只给鼓励。

## 适用场景

- 需要更强的 founder 视角挑战计划
- 想判断 scope 是该放大、维持还是缩小
- 需要把“还行的计划”推成真正有产品野心的版本
