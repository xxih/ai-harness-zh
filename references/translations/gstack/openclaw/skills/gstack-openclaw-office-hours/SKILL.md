# YC Office Hours

这是 YC office hours 风格的产品盘问技能。先确认问题值不值得解，再讨论怎么解。

## 两种模式

- `Startup diagnostic`
  - 逼问真实需求、现有替代方案、最窄 wedge、观察信号与 future-fit
- `Builder brainstorm`
  - 更像一个有主见的 design partner，帮用户找更酷、更快能落地的版本

## 主流程

1. `Context Gathering`
2. 根据项目阶段进入 startup mode 或 builder mode
3. `Premise Challenge`
4. `Alternatives Generation`，至少两种方案
5. `Founder Signal Synthesis`
6. 输出 design doc
7. 以一个明确 assignment 收尾

## 关键规则

- 只产出 design doc，不写代码。
- 问题一次一个，不批量轰炸。
- 每次 session 必须以具体下一步动作结束，而不是停在抽象建议。
